# Mandi Center — онлайн-меню «Карак»

QR-меню ресторана Mandi Center: арабская (йеменская) халяльная кухня, Астана. Вечернее меню чайной: графит, сталь, молоко и карамель карака. Главную роль играет типографика, декора нет.

**Сайт:** https://mandi-menu-chaynaya.vercel.app
**Репозиторий:** https://github.com/Diyar30under30/mandi-menu-chaynaya

- Русская версия: https://mandi-menu-chaynaya.vercel.app/
- Казахская версия: https://mandi-menu-chaynaya.vercel.app/kk/. Перевод — черновик, который ресторан должен проверить. Список сомнительных мест — в `data/kk-review.md`.

## Что умеет страница

- **Манди.** Выбор порции на 1, 2 или 5 персон с ценой за персону. Общий выбор «Сколько вас?» переключает порцию сразу во всех манди. Для судака отдельно выбирается барбекю или фрай.
- **Варианты.** Объём и размер напитков выбираются внутри позиции.
- **Фото.** Показываются по кнопке «Фото». Единственное большое фото на странице — поднос манди.
- **Поиск** по названиям и описаниям. На казахской странице ищутся и русские названия.
- **«Мой список».**
  - Добавление, количество, итог и экран «Показать официанту».
  - Список хранится только в браузере гостя (`localStorage`) и никуда не отправляется.
  - На казахском экране официанта под каждым блюдом мелко дублируется русское название.
- **Темы.** По умолчанию тёмная, светлая включается кнопкой.

## Файлы

| Путь | Что это |
|---|---|
| `data/menu.json` | Меню: названия, цены, порции. Единственный источник цен |
| `data/menu.kk.json`, `data/ui.kk.json` | Казахский перевод меню и интерфейса |
| `data/ui.ru.json` | Тексты интерфейса на русском |
| `src/tokens.css` | Все цвета, шрифты, размеры и отступы (дизайн-система) |
| `src/components.css` | Компоненты дизайн-системы |
| `src/menu.css` | Раскладка страницы, только на токенах |
| `src/app.js` | Поведение страницы, без библиотек |
| `build.js` | Собирает `index.html` и `kk/index.html` из данных |
| `verify.js` | Сверяет цены на страницах с данными |
| `DESIGN.md` | Описание дизайн-системы и правил |

## Как обновить

Нужен Node.js.

1. Поправить данные в `data/menu.json`. Если поменялся текст, поправить и перевод в `data/menu.kk.json`.
2. Собрать страницы и проверить цены:
   ```
   node build.js
   node verify.js
   ```
   `verify.js` должен написать «OK» для обеих страниц.
3. Выложить:
   ```
   vercel deploy --prod
   ```

## Правила

- Цены, названия, состав и порции берутся только из данных. Формат цены — «3 800 ₸» с неразрывными пробелами.
- Граммовки, аллергены, отзывы и сертификаты не выдумываются. Халяль указывается только как «Халяльная кухня».
- Цвета и размеры в CSS берутся только из `src/tokens.css`. Подробности — в `DESIGN.md`.
